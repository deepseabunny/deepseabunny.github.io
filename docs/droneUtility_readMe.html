drone-delivery-sim — compact README

Compact summary for the current simplified terminal-style simulator (fixed fleet, simplified controls, reset clears log).

Summary

  • Fleet: fixed-size (default 10 drones).
  • Deliveries: initial batch default 100; queue shown shortest-first.
  • Charging: asynchronous background charging; paused while a charging drone delivers and resumed after if needed.
  • Matching: greedy, non-blocking; deliveries sorted by ascending energy cost; best idle drone chosen per delivery.
  • UI: terminal log, Start/Pause/Step/Reset, Clear Deliveries, Safety Reserve slider, diagnostics (Show Idle / Show Blockers).

Controls (compact)

Control Action
[01] Start — Run assignment, charging, battery monitor loops
[02] Pause — Toggle pause/resume
[03] Step — Single synchronous assignment+charge step (when stopped)
[04] Reset — Reset to defaults (10 drones, 100 deliveries) and clear log
[05] Clear Deliveries — Remove all pending deliveries
[06] Speed — 1x / 2x / 4x
[07] Safety Reserve — Slider: battery margin required after assignment

Data model & key params

Entity Fields
Drone id; battery% ; task (idle|delivering); charging; pausedCharging
Delivery id; distance; energyCost = distance × ENERGY_PER_DISTANCE
Globals ENERGY_PER_DISTANCE=0.8; SAFETY_RESERVE=20% (default); CHARGE_RATE=2%/tick

Assignment deducts energy atomically when a delivery is assigned to avoid races.

Why drones go idle

  • Cost mismatch: long deliveries require more energy than available drones (given reserve).
  • High reserve: conservative SAFETY_RESERVE blocks assignments.
  • Greedy matching: not globally optimal; some drones may not match remaining deliveries.
  • Pause/resume: charging paused during delivery and resumed only when appropriate, so drones can appear idle.

Quick tuning

const ENERGY_PER_DISTANCE = 0.8;
const SAFETY_RESERVE = 20; // lower → more throughput
const CHARGE_RATE = 2;     // higher → faster recharge
const DELIVERY_TIME_MS = 500;

Use Show Blockers to list deliveries with no candidate drones and Show Idle to inspect idle drones.
