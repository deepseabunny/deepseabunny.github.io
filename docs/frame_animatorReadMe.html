Live Frame Animator

README — how to use, configure, and extend the single‑page animator that plays image frames as a live animation.

Overview

This single‑page animator accepts image frames (PNG, JPG, GIF) via file input or drag‑and‑drop, preloads them into memory, and plays them back in a canvas with live controls. It supports FPS control, loop modes (loop, once, ping‑pong), reverse, scrubbing, thumbnail reordering, and simple fit modes (contain, cover, stretch).

All processing happens locally in the browser. No files are uploaded to any server.

Features

  • Drag and drop or click to add multiple frames.
  • Play / Pause controls and frame stepping.
  • FPS slider for real‑time speed control.
  • Loop modes: Loop, Once, Ping‑Pong.
  • Fit modes: Contain, Cover, Stretch.
  • Thumbnail strip with drag‑to‑reorder frames.
  • Keyboard shortcuts for quick control.
  • Local preview and exportable master frames (use browser screenshot or external recorder).

Usage

Open the file

Save the animator HTML file to your machine and open it in a modern browser (Chrome, Edge, Firefox, Safari). No server required.

Add frames

  • Click the drop zone or drag image files onto it.
  • Supported types: image/png, image/jpeg, image/gif.
  • Frames are loaded in the order selected; use thumbnails to reorder.

Playback

  • Click Play to start. Click Pause to stop.
  • Use the FPS slider to change playback speed; the displayed FPS updates live.
  • Choose loop behavior from the Loop menu.
  • Use the Scrub slider to jump to any frame; scrubbing pauses playback.

Keyboard Shortcuts

Space play/pause • ← step back • → step forward

Controls Reference

Play Controls

  • Play — start animation loop.
  • Pause — stop playback but keep current frame.
  • Step Back / Step Forward — move one frame at a time.

Playback Settings

  • FPS — frames per second (1–60).
  • Loop Mode — Loop, Once, Ping‑Pong.
  • Fit Mode — Contain (letterbox), Cover (crop), Stretch (fill).

Thumbnail Actions

  • Click a thumbnail to jump to that frame.
  • Drag a thumbnail onto another to reorder frames.
  • Clear removes all frames from the session.
  • Shuffle randomizes frame order for quick tests.

Performance Tips and Best Practices

  • Image size — keep frames reasonably sized. 1080p frames are fine for modern machines; very large images increase memory and slow down previews.
  • Frame count — browsers can handle hundreds of small frames, but memory grows with count and resolution. For long animations, consider batching or using compressed review copies.
  • Use devicePixelRatio — the animator scales canvas to device pixel ratio for sharpness; if performance is slow, reduce canvas resolution in the code.
  • Preload strategy — the animator preloads images into memory. If you need streaming, adapt the loader to fetch and discard frames dynamically.
  • Export — to create a shareable video, record the canvas with a screen recorder or use MediaRecorder in the browser (advanced integration required).

Troubleshooting

Frames not loading

Check file types and ensure the browser has permission to read local files. If a file fails to load, it will be skipped and a message appears in the load progress area.

Playback stutters

  • Lower the FPS or reduce canvas resolution.
  • Close other heavy browser tabs or applications.
  • Use a machine with a dedicated GPU for smoother playback.

Drag reorder not working

Ensure you drag the thumbnail directly onto another thumbnail and release. On some touch devices drag events behave differently; use the thumbnail click to select frames instead.

Extending the Animator

Suggested enhancements

  • MediaRecorder export — add a button to record the canvas to WebM/MP4 using MediaRecorder.
  • Frame caching — implement LRU caching for very large frame sets to limit memory usage.
  • Sequence import — support importing numbered sequences and auto‑sorting by filename.
  • Layer blending — add opacity and blend modes to composite multiple frame layers for effects.
  • JSON manifest — accept a manifest file describing frame order, durations, and metadata for reproducible playback.

Developer notes

The animator is intentionally simple and self‑contained. All logic lives in the page script and uses the Canvas 2D API. For production pipelines, consider moving heavy training or rendering tasks to a backend service and using this tool for local review and director previews.
