1:1 Digital Warehouse Model

A 1:1 digital warehouse model built for an e‑commerce operation, designed to visually represent the full storage layout and surface key operational metrics. The system displayed precise item locations, item velocity (pick frequency), and detailed product information, enabling faster decision‑making and improved inventory flow. It also incorporated an A\‑based routing engine, allowing operators to visualize optimal travel paths through aisles and cross‑aisles for more efficient navigation.
