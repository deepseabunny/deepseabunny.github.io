Autonomous Logistics Assignment Agent

A real‑time, stream‑driven AI agent that tracks assets, reacts to events, and assigns new loads the moment a truck becomes free.

The agent consumes a continuous stream of logistics events (location updates, pickups, deliveries), maintains an internal state of assets and loads, and automatically creates new assignments when a truck completes a load and becomes available.

2. Real‑time stream processing model

The AI agent consumes a continuous stream of events from telematics, TMS, and driver apps. Each event is a fact about what just happened in the network.

2.1 Event types
  • Location events: ASSET_LOCATION_UPDATED
  • Load lifecycle: LOAD_PICKED_UP, LOAD_DELIVERED, LOAD_CANCELLED
  • Asset lifecycle: ASSET_BECAME_IDLE, ASSET_WENT_OFFLINE, ASSET_MAINTENANCE_REQUIRED
2.2 Example delivery event
{
  "eventType": "LOAD_DELIVERED",
  "assetId": "TRUCK-017",
  "loadId": "LOAD-9921",
  "timestamp": "2026-03-26T23:55:00Z",
  "location": { "lat": 33.30, "lng": -111.90 }
}

The agent applies each event to its internal state, then evaluates whether any asset has transitioned into a free and assignable state.

3. State update and free‑asset detection

For every incoming event, the agent first updates the canonical state, then runs detection logic to find assets that are now idle and ready for a new load.

3.1 Applying events to state
function applyEventToState(event, state) {
  switch (event.eventType) {
    case "ASSET_LOCATION_UPDATED":
      updateAssetLocation(state, event);
      break;
    case "LOAD_PICKED_UP":
      markLoadPickedUp(state, event);
      break;
    case "LOAD_DELIVERED":
      markLoadDelivered(state, event);
      freeAssetFromLoad(state, event.assetId, event.loadId);
      break;
    case "ASSET_BECAME_IDLE":
      markAssetIdle(state, event.assetId);
      break;
    // ...other event handlers
  }
}
3.2 Detecting free assets
function detectFreeAssets(state) {
  return state.assets.filter(
    (a) => a.status === "IDLE" && !a.currentLoadId
  );
}

This mirrors the maintenance agent pattern: instead of “room needs maintenance”, the trigger is “truck is now idle and unassigned”.

4. Assignment logic and alerting

When an asset becomes free, the agent selects the best next load based on distance, priority, and time windows, then creates an assignment and alerts operators and drivers.

4.1 Choosing the next load
function chooseBestLoad(asset, candidateLoads) {
  // Example heuristic: prioritize by (priority, distance, pickup time window)
  const scored = candidateLoads.map((load) => {
    const distance = haversine(asset.currentLocation, load.pickupLocation);
    const priorityScore = load.priority === "HIGH" ? 3 : load.priority === "MEDIUM" ? 2 : 1;
    const score = priorityScore * 1000 - distance; // higher is better
    return { load, score };
  });

  scored.sort((a, b) => b.score - a.score);
  return scored.length > 0 ? scored[0].load : null;
}
4.2 Creating an assignment
function assignNextLoadToAsset(asset, candidateLoads) {
  const load = chooseBestLoad(asset, candidateLoads);
  if (!load) return null;

  const assignment = {
    assignmentId: `ASG-${Date.now()}`,
    assetId: asset.assetId,
    loadId: load.loadId,
    status: "ACTIVE",
    createdAt: new Date().toISOString(),
    completedAt: null
  };

  asset.status = "IN_TRANSIT";
  asset.currentLoadId = load.loadId;
  load.status = "ASSIGNED";
  load.assignedAssetId = asset.assetId;

  return assignment;
}

5. AI agent loop over the stream

The logistics agent reacts to each event in the stream, updates state, detects free assets, and assigns new loads in real time. 

function logisticsAgentOnEvent(event, state) {
  // 1. Update internal state from the event
  applyEventToState(event, state);

  // 2. After state change, detect free assets
  const freeAssets = detectFreeAssets(state);

  // 3. For each free asset, try to assign a new load
  freeAssets.forEach((asset) => {
    const candidateLoads = findUnassignedLoadsNearAsset(state, asset);
    const assignment = assignNextLoadToAsset(asset, candidateLoads);
    if (assignment) {
      state.assignments.push(assignment);
      dispatchAssignmentAlert(assignment, asset);
    }
  });
}

This loop can run inside a stream processor (Kafka consumer, Kinesis app, Flink job, etc.), giving you millisecond‑level reaction to network changes.
