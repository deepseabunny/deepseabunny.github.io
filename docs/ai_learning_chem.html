2. Learn the axes

Rows · Layers of abstraction

Row 1 – Primitives: the atoms (prompts, embeddings, LLMs).

Row 2 – Compositions: molecules built from primitives (RAG, vectors, guardrails, multimodal).

Row 3 – Deployment: how systems ship (agents, finetuning, frameworks, red-teaming, small models).

Row 4 – Emerging: frontier behaviors (multi-agent, synthetic data, interpretability, thinking).

Columns · Generations of capability

G1 – Reactive: prompt-in, response-out; basic agents and tools.

G2 – Retrieval: memory and search via embeddings and vectors.

G3 – Orchestration: frameworks and RAG pipelines wiring components together.

G4 – Validation: guardrails, red-teaming, interpretability.

G5 – Models: frontier model capabilities: LLMs, multimodal, small models, explicit thinking.

Mental model
Atoms → Molecules → Systems → Ecosystems

3. Map to real systems

Use this as a quick “translation” from the table to real-world stacks.

  • Pr + Lg → simple chat assistant with good prompting.
  • Em + Vx + Rg → retrieval-augmented knowledge base.
  • Fc + Ag + Fw → tool-using AI agent built on a framework.
  • Gr + Re + In → safety and validation layer for enterprise AI.
  • Ma + Sy + Th → experimental multi-agent, synthetic-data, reasoning-heavy systems.

When you design an AI application, you’re basically choosing which row you’re operating in and which generation you’re leaning on.
