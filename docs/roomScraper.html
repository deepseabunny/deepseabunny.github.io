roomScraper README

Short description

A Playwright-based scraper that scrolls Booking.com search results, extracts property name and rate, deduplicates entries, and writes copy-paste friendly output (TSV + Markdown + CSV). Designed to handle lazy-loading via an initial continuous scroll and controlled scroll passes with DOM + network idle detection.

Prerequisites

  • Node.js (v16+ recommended)
  • Install Playwright: npm install playwright
  • Install browser binaries: npx playwright install

Files produced

  • mesa_prices.jsonl — one JSON object per line (minimal: { "name": "...", "price": "..." })
  • mesa_prices.csv — CSV with header name,price
  • mesa_prices_summary.json — run summary and basic stats
  • Console output: TSV (tab-separated) and Markdown table for quick copy/paste

Quick install and run

# install playwright and browsers
npm install playwright
npx playwright install

# headless (default)
MAX_PROPERTIES=100 CONCURRENCY=4 node roomScraper.mjs

# headful (visible browser) with slow motion for debugging
HEADFUL=1 SLOWMO=80 MAX_PROPERTIES=100 node roomScraper.mjs

What it does (high level)

  1. Open Booking search results for the configured city and dates (today → tomorrow).
  2. Initial continuous scroll for 10 seconds to trigger lazy-loading of many results.
  3. Controlled scroll passes (up to MAX_SCROLL_PASSES) that:
    • Scroll to the last visible card
    • Click any “Load more / Show more” controls if present
    • Wait for DOM mutations and network activity to become idle before scraping
  4. Parse visible property cards and extract name and price.
  5. Deduplicate by stable key: hotelId → href → normalized name.
  6. Stream results to mesa_prices.jsonl and append to mesa_prices.csv. Print TSV and Markdown table to console for easy copy/paste.

Output format (copy-paste friendly)

TSV (paste into spreadsheet): name[TAB]price

name price SureStay Plus by Best Western Mesa Superstition Springs $67 Holiday Inn Express & Suites Phoenix - Mesa West by IHG $99

Markdown (for README or notes):

| name | price |
| --- | --- |
| SureStay Plus by Best Western Mesa Superstition Springs | $67 |
| Holiday Inn Express & Suites Phoenix - Mesa West by IHG | $99 |

Troubleshooting tips

  • Too few results: run with HEADFUL=1 and SLOWMO=80 to watch the page; increase MAX_SCROLL_PASSES or the initial continuous scroll duration.
  • Duplicates: the script dedupes by ID/href/name; inspect mesa_prices.jsonl to see name variations and consider normalizing further.
  • No prices captured: network JSON capture may miss some offers; the script falls back to reading card text and then to opening property pages. Try headful mode to observe dynamic loading or increase worker timeouts.
  • Checkpointing: checkpoint.json stores { collected, scrollPosition }. Use IGNORE_CHECKPOINT=1 to start fresh.
  • Rate limiting / Captcha: reduce concurrency, add longer delays, or use proxies if you hit anti-bot measures.

Notes and best practices

  • Run short, respectful scraping sessions. Avoid aggressive scraping that may violate site terms or trigger rate limits.
  • For reproducible results, run with the same CITY, MAX_PROPERTIES, and CONCURRENCY settings.
  • Use KEEP_OPEN=1 to leave the browser open for manual inspection after a run.
