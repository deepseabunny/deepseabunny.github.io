Barcode Generator Endpoint

This document describes how to use the barcode generator HTML endpoint that renders a barcode image based on URL parameters. The page outputs only the barcode image (no UI, no text), making it ideal for embedding in dashboards, tools, and automations.

1. Overview

The generator is a single self-contained HTML file (for example, barcode.html). When requested with query parameters, it draws a barcode onto a <canvas> and shows nothing else.

Conceptually:
barcode.html?val=YOUR_DATA&barcode=TYPE → page responds with a rendered barcode image.

2. Supported barcode types

The following barcode formats are supported via in-browser libraries:

Barcode Type barcode parameter value Notes
PDF417 pdf417 2D stacked barcode, good for dense data.
QR Code qr or qrcode Standard QR code.
Code128 code128 Linear barcode, common in logistics.
DataMatrix datamatrix Compact 2D code, often used in manufacturing.
Aztec aztec 2D code, robust for small print areas.

3. File contents (generator HTML)

Save the following as barcode.html (or any name you prefer):

<!DOCTYPE html>
<html>
<head>
<meta charset="UTF-8">
<title>Barcode</title>
<style>
  body {
    margin: 0;
    background: #fff;
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;
  }
  canvas { display: block; }
</style>
</head>
<body>

<canvas id="barcodeCanvas"></canvas>

<!-- Libraries -->
<script src="https://cdn.jsdelivr.net/npm/bwip-js/dist/bwip-js-min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/qrcode/build/qrcode.min.js"></script>

<script>
  const canvas = document.getElementById("barcodeCanvas");

  function getParams() {
    const p = new URLSearchParams(location.search);
    return {
      val: p.get("val") || "",
      type: (p.get("barcode") || "").toLowerCase()
    };
  }

  function renderPDF417(value) {
    bwipjs.toCanvas(canvas, {
      bcid: "pdf417",
      text: value,
      scale: 3,
      includetext: false
    });
  }

  function renderCode128(value) {
    bwipjs.toCanvas(canvas, {
      bcid: "code128",
      text: value,
      scale: 3,
      includetext: false
    });
  }

  function renderDataMatrix(value) {
    bwipjs.toCanvas(canvas, {
      bcid: "datamatrix",
      text: value,
      scale: 3,
      includetext: false
    });
  }

  function renderAztec(value) {
    bwipjs.toCanvas(canvas, {
      bcid: "azteccode",
      text: value,
      scale: 3,
      includetext: false
    });
  }

  function renderQR(value) {
    QRCode.toCanvas(canvas, value, { margin: 1 });
  }

  (function main() {
    const { val, type } = getParams();
    if (!val) return;

    switch (type) {
      case "pdf417":   return renderPDF417(val);
      case "code128":  return renderCode128(val);
      case "datamatrix": return renderDataMatrix(val);
      case "aztec":    return renderAztec(val);
      case "qr":
      case "qrcode":   return renderQR(val);
      default:         return renderQR(val); // fallback
    }
  })();
</script>

</body>
</html>

4. Basic usage

4.1 Direct browser usage

Once the file is hosted (or opened via a local server), you can generate barcodes by visiting URLs with the appropriate query parameters:

  • PDF417
    barcode.html?val=HELLO123&barcode=pdf417
  • QR Code
    barcode.html?val=HELLO123&barcode=qr
  • Code128
    barcode.html?val=HELLO123&barcode=code128
  • DataMatrix
    barcode.html?val=HELLO123&barcode=datamatrix
  • Aztec
    barcode.html?val=HELLO123&barcode=aztec

4.2 Embedding as an image

Because the page renders only a barcode image, you can embed it directly in other pages using an <img> tag: 

<img
  src="barcode.html?val=ORDER-12345&barcode=code128"
  alt="Order barcode"
/>

Any system that can construct a URL can now “ask” this HTML file to render a barcode on demand.

5. Parameters

Parameter Required Description
val Yes The data encoded into the barcode (string).
barcode Recommended The barcode type. If omitted or unrecognized, the generator falls back to QR code.

6. Notes & extensions

  • Background: Currently white. You can change the body background or canvas styling for transparency or theming.
  • Scale: The scale parameter in bwip-js calls controls barcode size; increase for print use.
  • Offline use: To run fully offline, download the JS libraries and reference them locally instead of via CDN.
  • Error handling: If val is missing, the page renders nothing.

This README is meant to live alongside barcode.html as a quick operational guide.
